## Documentation

Project documentation lives in `docs/`; start with `docs/README.md`. Keep project-specific explanations there and update them with behavior changes. Use root `audit.md` for the FSS Stack audit process.

Shared FSS Stack instructions and extension payloads live in Stackforge's `fssstack/` source tree, published to Forum as `mp-lb/fssstack`. Read an extension with `fm read extensions/<extension>/README.md --store mp-lb/fssstack`, or use the same path under the Stackforge source tree. This project does not require a private Forum store; document any project-specific sync mapping when one is configured.
