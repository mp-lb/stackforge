# ArcNet deployment extension

When the user asks to add `arcnet.md`, or selects `arcnet` in `fssstack.yaml`, apply it after the base project validates.

Read and follow the **[ArcNet setup guide](https://github.com/mp-lb/stackforge/blob/main/arcnet/SETUP.md)**. It owns the installation steps, requirements, supported deployment targets and validation. See the [ArcNet README](https://github.com/mp-lb/stackforge/blob/main/arcnet/README.md) for the target file tree.

This file is only the FSS Stack entry point. ArcNet does not require FSS Stack; keep its setup instructions in ArcNet rather than duplicating them here. The base FSS Stack shell remains deployment-free until this extension is requested.
