# Context composition

Start with the actual `shell/context/` files, not a monolithic agent-file template. Adapt the project, development, validation, documentation and delivery blocks to the assembled repository. Keep `context/context.md` first, and preserve `scripts.md`.

Project types, selected extensions and organization augmentations add explicit imports to `context/index.md`. Read [Context files](context-files.md) before changing the compilation contract.
