# Context sources

The shell keeps project-specific context in `context/` and imports shared agent context, standards, development, validation, scripts, documentation and code style from Forum. MAP Lab can replace the Fssstack development link with its own development block. Add project-specific instructions locally when needed.

Import `ui.md` remotely for shadcn frontends and the ArcNet and delivery contexts from the `mp-lb/arcnet` store when ArcNet is installed. Product and extension-specific instructions remain local where they differ. See [Context files](../standards/context-files.md).
