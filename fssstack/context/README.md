# Context sources

The shell keeps project-specific context in `context/` and imports shared standards, development, validation, scripts, documentation and code style from Forum. Add project-specific instructions locally when needed.

Import `ui.md` remotely for shadcn frontends and the ArcNet context from the `mp-lb/arcnet` store when ArcNet is installed. Product and extension-specific instructions remain local where they differ. See [Context files](../standards/context-files.md).
