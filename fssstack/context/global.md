# Context ownership

Universal context maintenance now ships in `shell/context/context.md`. Install the shell's complete `context/` composition and follow `standards/context-files.md`.

MapLab workflow, standards and local toolchain instructions belong to the FSS Stack augmentation in `mp-lb/augmentations`, which supplies its own `context/` payloads. Frontend/backend rules are selected by project type; optional capability rules come from `extensions/<extension>/context/`.

Do not import this migration note into project agent files.
