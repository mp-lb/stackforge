# Mobile app inputs

Copy the `inputs.example.env` generated by [Expo setup](SETUP.md). Supply the app name and slug, Expo owner and project ID, bundle ID and package name, App Store Connect app ID, and production API and auth settings.

For developer accounts and store records, follow the [mobile app release checklist](https://hyperdoc.forumlabs.net/6af52eaf-37a0-451d-b55b-a852da302bf5).
