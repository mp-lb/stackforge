### Desktop conventions

This project applies MapLab's Electron augmentation. Preserve its Electron Kit integration, packaged offline fallback, window state and browser-auth handoff where configured. Keep hosted frontend compatibility with supported installed desktop versions.

Signing, release hosting and updates follow the project's actual delivery workflow and ArcNet consumers. A web deployment is not a desktop release. Read `fm read electron.md --store mp-lb/augmentations` before changing these mechanisms; keep credentials out of context.
